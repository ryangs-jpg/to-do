# 한걸음

제목만 적어 기록하고, 지금 할 일 하나에 집중하는 한국어 할 일 앱입니다.

## 실행

Node.js가 설치된 환경에서 프로젝트 폴더에서 `node server.cjs`를 실행하고 http://127.0.0.1:4173 을 여세요. `dist/index.html`을 직접 열 수도 있지만, 안정적인 브라우저 저장과 알림 권한 처리를 위해 HTTP 서버 사용을 권장합니다.

## 사용

- 입력창에 제목을 쓰고 Enter를 누르면 수집함에 저장됩니다. Ctrl/Cmd + K로 입력창에 이동합니다.
- 오늘의 계획은 최대 3개입니다. 현재 진행하는 일은 하나이며, 다른 일을 시작하면 이전 일은 자동으로 보류합니다.
- 제목이나 더보기 버튼에서 돌아올 메모, 다음 행동, 하위 단계, 일정, 우선순위, 반복, 알림 등을 수정합니다. 변경은 자동 저장됩니다.
- 완료와 삭제 직후에는 실행 취소를 제공합니다. 완료 목록에서는 완료를 취소할 수 있습니다.
- 반복 일을 완료하면 다음 날짜의 새 할 일이 만들어집니다.
- 설정에서 타이머 표시, 브라우저 알림, JSON 백업과 가져오기를 사용할 수 있습니다.

## 저장과 알림

데이터는 사용 중인 브라우저의 localStorage에 저장됩니다. 기기 간 자동 동기화는 없습니다. 브라우저 데이터 삭제에 대비해 백업을 내려받으세요. 가져오기는 기존 기록과 합쳐지며 같은 ID의 기존 기록을 덮어쓰지 않습니다. 알림은 브라우저 권한을 허용하고 앱을 열어둔 동안 작동합니다. 외부 서비스에 할 일 내용을 전송하지 않습니다.

## 확인한 항목

JavaScript 구문 검사 및 브라우저에서 할 일 추가, 작업 시작과 전환, 자동 보류, 메모·하위 단계 저장, 새로고침 후 복원, 완료와 실행 취소를 확인했습니다.
